# How to use your six resources

These resources have different purposes. The sequence below is a recommendation for this workbook, not a requirement imposed by their authors. External materials are linked, not copied; their own terms and course policies apply.

| Resource | Use it for | Place in our path |
| --- | --- | --- |
| [CS50P](https://pll.harvard.edu/course/cs50s-introduction-programming-python) | Python functions, testing, debugging, files, and classes | Review specific gaps; you already have Python experience |
| [CS50x](https://cs50.harvard.edu/x/) | Explanations of C, arrays, algorithms, memory, and data structures | Alongside core C++ practice; keep C and C++ syntax/rules distinct |
| [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) | Longer projects with concrete internals | After our integration project, choose one tutorial with prerequisites you meet |
| [Git/GitHub video](https://www.youtube.com/watch?v=S7XpTAnSDL4) | A visual companion to Git practice | Alongside Lab 1; completing the video is not a gate |
| [System Design Primer](https://github.com/donnemartin/system-design-primer) | Distributed services, scalability, and system-design interviews | Optional later; outside the required C++ foundation |
| [Anthropic courses](https://github.com/anthropics/courses) | Claude APIs, prompting, evaluations, and tool use | Optional for LLM applications; not a substitute for ML/CV fundamentals |

## A CS50-to-C++ study session

1. Study one idea, such as memory or arrays.
2. Explain it in plain English and draw a tiny example.
3. Read the matching C++ Concepts section. Ask which rules differ from C or Python.
4. Implement a selected exercise, inspect a failure, and add one test.
5. Commit the change with a sentence explaining why it was needed.

Follow CS50's own academic-honesty rules for its assignments. Our exercises are independent practice, not submissions for Harvard coursework.

## Picking a Build Your Own X project

Choose by prerequisites and interest, not prestige or number of lines. Start with a command-line tool or a small renderer if you already understand the required geometry. An operating system, allocator, or full neural-network implementation is not a mandatory next step.

Before starting, write down the required language features, dependencies, and the smallest runnable milestone. After following a tutorial, implement one feature the tutorial did not supply and test it. That is evidence of independent understanding.

## Scope boundary

There are no required distributed-system interview exercises or LLM API lessons here. Robotics/embedded/CV specialization comes after general programming and alongside mathematics and hardware coursework. We retain useful algorithms without optimizing the curriculum for contest performance.
