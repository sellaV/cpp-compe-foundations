# Later: libraries and modern C++

Start with the [20 core exercises](../README.md). This track introduces standard algorithms, optional, hash maps, smart pointers, move semantics, templates, parsing and RAII afterward.

Some tasks deliberately revisit a core problem with a library-based interface. Compare what the library removes and what rules it adds. You do not have to repeat every similar problem: follow the [library learning guide](../docs/LIBRARIES.md).

From the repository root:

```bash
python3 later/tools/run.py --list
python3 later/tools/run.py 01
python3 later/tools/run.py all --reference
```

Each folder contains the statement, starter, tests and explained reference. The original optional engineering track remains in applied/.
