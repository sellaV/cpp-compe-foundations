# Practical libraries and modern C++

Use this track after the relevant core concepts. You do not need all 18 core tasks first.

Start with **16 (streams), then 15 (checked parsing)** for the integration project. Continue with **03 (iterators/algorithms), 08 (map-backed records), 13 (sorting), 10 (ownership/moves), and 18 (RAII)**. These are seven practical tasks, not speed exercises.

01 and 02 are short comparisons with manual core implementations. 06 (owned list), 07 (value operators), 09 (polymorphic cloning), and 17 (variant) are selectable extensions. Full details: [library guide](../docs/LIBRARIES.md).

```bash
python3 later/tools/run.py --list
python3 later/tools/run.py 16
python3 later/tools/run.py 16 --reference
```

13 exercises remain. Gaps in IDs preserve existing paths. Pair-sum, unique-window, anagram, advanced transform and generic frequency drills were removed. You can learn maps through inventory records, sorting through ranked records, and ownership through resource management.
